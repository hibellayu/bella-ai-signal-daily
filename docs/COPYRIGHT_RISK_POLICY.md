# Bella's AI 趨勢日報 版權與來源風險控管

建立日期：2026-07-10（台北時間）

## 控管目的

本站的內容定位是 AI 趨勢整理、評論與行銷應用解讀，不是新聞全文轉載或新聞資料庫。風險控管的目標，是讓內容能被搜尋與引用，同時尊重原媒體與作者的著作權。

## 核心原則

1. 事實可以整理，表達不可搬運。
2. 每則資訊必須保留來源媒體名稱與原文連結。
3. 摘要只提供脈絡，不替代原文閱讀。
4. 觀點、What / So What / Now What 必須用行銷策略者角度重新撰寫。
5. 示範內容、來源日期不確定內容、空日報，不進入 sitemap 與每日靜態頁。

## 生成規則

- RSS / Atom 來源摘要只截取短片段供模型判斷，目前上限為 220 字元。
- Prompt 明確要求不得複製來源文章句子、不得翻譯來源段落、不得用接近原文的連續句型改寫。
- 模型只能依候選新聞的事件事實、媒體名稱、發布日期與原文 URL 產生解讀。
- 若來源資訊不足以確認事件，應降低收錄優先，不用推測補成事實。
- Now What 以小行動建議為主，不把新聞內容重寫成可取代原文的完整報導。

## 前台呈現規則

- 每則資訊的來源媒體名稱直接連到原文。
- Footer 顯示內容使用聲明：

```text
本站內容為 AI 趨勢整理、評論與行銷應用解讀；新聞來源與原文著作權屬各原媒體與作者所有。若需完整內容，請閱讀原文。
```

## SEO 收錄規則

- 正式日報可產生 `/daily/YYYY-MM-DD/` 靜態頁並進入 sitemap。
- `isDemo: true` 或 `noindex: true` 的日報只保留於互動版，不產生每日靜態頁、不進入 `/daily/` 列表、不進入 sitemap。
- 空日報不產生每日靜態頁、不進入 sitemap。

## 下架與修正流程

若發現內容疑似過度接近來源表達、來源連結錯誤、日期不準或原媒體提出疑慮：

1. 先將該日報或該則內容標記為 `noindex: true`。
2. 重新執行 `python3 scripts/static_site.py`，讓 sitemap 移除該頁。
3. 修正內容為策略觀點重寫，或移除該則資訊。
4. 更新 `CHANGELOG.md` 記錄原因與處理方式。
5. 如已被 Google 收錄，再到 Google Search Console 申請移除或重新檢索。

## 判斷紅線

- 不貼全文或大段原文。
- 不用原媒體完整段落做翻譯。
- 不把多篇新聞拼成可替代原文的完整整理包。
- 不把來源連結改成媒體首頁。
- 不收錄無法確認發布日期或來源明顯錯置的正式 SEO 頁。
